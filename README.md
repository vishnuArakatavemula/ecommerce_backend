# Spring Boot E-Commerce Backend

A RESTful E-Commerce backend application developed using Java and Spring Boot.

## Technologies

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST API
- Postman

## Features

- User registration
- Category management
- Product management
- Cart management
- Add products to cart
- Retrieve cart
- Order creation
- Order items
- Order total calculation
- Pagination and sorting
- Input validation
- Exception handling
